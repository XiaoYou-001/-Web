# 智绘旅游

Vue 3 + Vite 旅游应用，包含线路规划、景点与酒店浏览、票务演示、AI 客服和 Go WebSocket 聊天服务。

## 启动

使用 Node.js 22.12 或更高版本，在项目根目录执行：

```powershell
npm ci
npm run dev
```

AI 后端通过 `npm run start:backend` 启动，密钥和配置参见 [后端指南](NODEJS_BACKEND_GUIDE.md)。Go 聊天服务在 `go-chat-server` 目录通过 `go run .` 启动。

## 接口与错误处理

前端 HTTP 请求统一通过 `apiClient`，AI 请求由 `aiService` 调用。默认基地址为 `/api`，开发时 Vite 转发至 Node 服务，生产部署需配置 `/api` 反向代理，或构建前设置公开变量 `VITE_API_BASE_URL`。普通请求默认 10 秒超时，AI 默认 45 秒，可分别通过 `VITE_API_REQUEST_TIMEOUT_MS`、`VITE_AI_REQUEST_TIMEOUT_MS` 调整。

请求会区分取消、超时、网络故障、限流、权限错误、服务未配置及响应格式错误。临时故障可手动重试，不自动重发请求。停止等待、切换客服/模型、刷新对话或离开页面会取消旧请求并清理定时器，过期响应不写入当前会话。

线路当前仍保存在本地账号数据中。保留的线路 HTTP 适配器只有在显式配置 `VITE_ROUTES_API_BASE_URL` 后才启用，未配置时明确报“尚未接入”，接口失败也不会悄悄返回模拟推荐。适配器不再读取旧版 `authToken`；本地演示账号不能作为真实后端登录凭证。

## 本地账号与个人数据

当前账号属于本地演示，仅保存在此浏览器中，请勿使用真实密码；尚未接入真实后端认证、支付或短信发送。微信入口也为需要主动确认的演示流程，详见 [微信说明](WECHAT_INTEGRATION_GUIDE.md) 和 [手机号验证说明](SMS_INTEGRATION_GUIDE.md)。

线路、每日行程、景点收藏、酒店收藏和价格订阅按账号 ID 保存。刷新或重新登录后恢复同一账号的数据，切换账号时清空当前展示，再读取新账号的数据。个人中心的收藏数量包含景点、酒店及已收藏线路。

- 新账号的“我的线路”为实际空列表；推荐线路仍作为可选的演示内容。
- 价格订阅只保存订阅信息，实际价格监控与短信、微信推送尚未接入。
- 保存失败时保留编辑草稿，不显示成功，也不提前更新收藏或订阅状态。
- 同一账号在其他标签页修改的数据会通过浏览器存储事件刷新；当前存储不提供跨设备同步或数据库级并发事务。

个人业务数据使用 `travel_data:v1:<账号ID>` 键，包含版本、所属账号、线路、收藏、订阅和行程。读取时校验版本和结构，数据损坏或版本不兼容时保留原始值并显示错误，不自动覆盖。

旧版未记录所属账号的 `price_subscriptions` 和 `user_itineraries` 原样保留，不自动归给任何账号，也不自动删除。旧版仅保存在页面内存中的线路、收藏在刷新后无法恢复。

## 聊天室

聊天服务与前端需要使用同一版协议。连接携带账号 ID 和房间 ID，服务端按连接所属房间广播，并按房间内不同账号统计在线人数；多个标签页使用同一账号计为一人。当前身份来自本地演示账号，尚无服务端登录凭证校验。

每条消息带独立 ID，前端收到服务器回显后确认服务器已接收。10 秒未确认或连接断开时标记为“未确认送达”，可手动重发；同一 ID 在服务端最近 2048 条消息缓存中只广播一次，重发仅返回原消息回执。缓存淘汰或服务器重启后不保证去重，回显也不代表其他用户已经阅读。

断线使用有上限的指数退避重连，心跳无响应会主动重建连接，离开房间时释放监听器和定时器。聊天记录按账号、房间保存在浏览器，最多保留最近 100 条；服务器没有永久消息存储或离线补发功能。损坏的本地记录会保留，用户主动清除后才恢复写入。

默认连接当前站点的 `/ws`，HTTPS 页面自动使用 `wss`。开发环境由 Vite 转发至 `127.0.0.1:8080`；生产环境需要将 `/ws` 反向代理至 Go 服务并开启 WebSocket 升级，或构建前设置 `VITE_CHAT_WS_URL` 为可访问的 WebSocket 地址。

## 表单与操作反馈

登录和注册复用账号服务的手机号、密码基础校验规则。提交时同时显示各字段错误，并将焦点移到第一个错误输入；修改字段后清除对应旧错误，保存失败时保留草稿。手机号提交前修剪首尾空格，密码不做修剪。账号或存储错误持续显示在表单内，成功提示可跨页面显示。

全站通用操作提示通过 `useFeedback` 和 `FeedbackHost` 展示，业务页不再直接调用浏览器 `alert/confirm`。同类重复提示合并，最多显示三条；成功、信息和注意提示 5 秒后关闭，错误提示由用户关闭。AI 对话和地图等已有的局部错误继续在原位置展示。

删除线路、取消订阅、清空聊天记录和切换账号等动作使用原生 `dialog` 确认框，默认聚焦取消按钮，支持 Tab 焦点约束和 Escape 取消。同一时间只处理一个确认；关闭或离开所属页面、切换账号会取消等待中的确认，异步恢复后还会检查账号或聊天室是否仍匹配。提示组件卸载时清理计时器和待处理动作。

预订、支付、订单详情、线路分享等未接入真实服务的入口明确说明演示状态，不报告真实业务成功；点击演示支付不再把订单直接标为已支付。酒店评价只保存在当前页面，景点复制信息只在剪贴板写入成功后提示成功，拒绝权限或取消分享都有对应处理。

## 景点地图与页面清理

地图仅在切换至地图视图后加载。构建前配置公开的高德 Web 端 `VITE_AMAP_KEY`；留空时显示未配置提示，并可直接切回列表，不请求地图脚本。需要安全代理时设置 `VITE_AMAP_SERVICE_HOST`（例如 `https://maps.example.org/_AMapService`），按[高德安全密钥说明](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)配置代理，将安全密钥保存在服务端。项目未提供该代理，Web Key 的域名和授权范围也需在高德控制台配置。

脚本加载会合并并发请求，成功后复用 SDK。超时或失败可在页面内重试；离开地图或页面时取消当前加载、移除本次失败或取消的脚本和回调，并解绑标记及地图事件、销毁地图实例。其他调用仍在等待时保留共享加载，不删除第三方脚本。SDK 加载和地图渲染各有 10 秒超时，不再依赖固定延时等待 DOM。

现有景点没有真实经纬度，地图仍按地区生成固定示意位置，页面明确提示不能用于精确定位。筛选或排序不会使同一景点随机漂移，地图展示全部筛选结果，列表与网格继续分页。接入真实景点接口后，应使用高德坐标系的实际坐标替换示意位置。

票务页的演示搜索会使用点击时提交的条件，再次搜索会取消同类旧任务；重置或离开页面会取消待执行任务，避免旧结果回写。`test:map` 使用模拟 SDK、脚本和计时器验证加载合并、取消、重试和卸载清理，无需真实地图 Key；真实高德鉴权、底图与外网连接需在配置后另外联调。

## 加载体积

所有业务页面沿用路由懒加载。Element Plus 的组件、样式及中文日期配置仅由票务页引入；SVG 图标仅由使用图标的页面引入，并复用同一分包。

本轮在相同依赖版本下的生产构建对比（十进制 KB）：

| 构建资源 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 应用入口 JS | 1,058.0 KB | 129.78 KB |
| 应用入口 JS（gzip） | 351.2 KB | 50.45 KB |
| 应用入口 CSS | 337.0 KB | 3.05 KB |

首页还需加载其页面、图标和样式分包，不能把入口体积当作首页总下载量。以上数字不含远程图片、外部图标字体、接口请求或网络耗时，尚未进行真实网络下的首屏时间测量。

`npm run build` 会生成 Vite manifest 并自动检查体积预算；也可在已有构建后单独执行 `npm run check:bundle`。检查会递归统计入口及登录、首页、票务冷启动时的静态 JS/CSS 依赖，共享文件只计一次，未访问的路由不计入首屏。超预算会返回非零退出码。

预算使用 KiB（1024 字节）：入口 JS/CSS 为 160/10，登录页为 180/10，首页为 256/32，票务页为 550/150。依赖升级后如需调整预算，应先确认体积增长来源。

## 图片与图标资源

入口不再请求外部图标字体或 CSS，图标使用已安装依赖中的 SVG，随业务页面分包加载。网站图标、客服头像、图片兜底图和首页背景兜底图均放在 `public` 中，普通图片与头像使用不同兜底。微信客服没有真实二维码时明确显示未配置。

页面图片通过 `AppImage` 渲染，默认使用浏览器原生懒加载、异步解码，并设置宽高以预留空间；首页和酒店页的主背景优先加载，导航卡片图片也使用懒加载。头像上传的图片数据仍可正常显示，已有真实远程图片地址保留，`example.com` 的旧占位地址直接改用本地兜底，避免无效请求。

加载失败后只切换一次兜底图，切换图片地址会重新尝试加载；前一个请求迟到的错误不会覆盖当前图片。远程照片仍依赖网络与来源站点，兜底只能保证页面有替代画面，并不代表图片已经缓存或支持完整离线浏览。新增图片入口应复用 `AppImage`，不要直接添加外部图标字体或随机照片二维码。
